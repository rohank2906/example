# Post Training Submission — CSV Reader

Test submission for the LLM Post Training course evaluator.

## Files

- `prompt.md` — the prompt the student authored.
- `justification.md` — A/B comparison of two candidate responses to the prompt.
- `golden_response.py` — the reference implementation.

## Task

Write a Python function that reads a CSV file and returns its rows as a list of dictionaries.

## Run

```bash
python golden_response.py
```
